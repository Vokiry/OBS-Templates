# SYSTEM — OBS Broadcast Templates

TUI-inspired визуальная система для стрима в стилистике **system24**: эфир как строгий интерфейс технической системы с состояниями (`starting` → `main` → `chatting` → `focus` → `brb` → `ending`).

Тёмный монохромный UI, живой интерактивный чат со смайлами 7TV, всеми бейджами Твича и опросами в реальном времени, вспышки донатов с поддержкой голосовых сообщений (TTS) и ответов ИИ, заказ музыки с YouTube, таймер с управлением из OBS и динамические терминальные фоны. Всё работает локально, без сторонних платных сервисов.

## Все основные функции так или иначе работают, если что то работает коряво или не работает вовсе - feel welcome обратиться в [#issues](https://github.com/Vokiry/OBS-Templates/issues).

## Возможности

- **6 готовых сцен**: Starting Soon, Main (Gameplay), Chatting, Focus, Break (BRB), Ending.
- **Импорт в OBS за 1 клик**: готовый файл коллекции сцен `obs/SYSTEM_Scene_Collection.json`. Безопасный запуск: пользовательские источники (веб-камеры, захваты игры, микрофоны) никогда не затираются при повторных стартах.
- **Два режима работы (`Stream Mode` vs `Config Mode`)**:
  - `Боевой режим (Stream Mode)`: чистый, максимально легковесный сервер для прямого эфира без лишней нагрузки на CPU и RAM.
  - `Режим настройки (Config Mode)`: полноценная веб-панель настроек (`http://localhost:8787/settings`) для настройки каналов, токенов, звуков и проверки статусов.
- **Интерактивный Twitch-чат**:
  - Анонимное подключение через Twitch IRC без токенов;
  - Встроенные смайлы Twitch, глобальные и канальные смайлы **7TV** с переключением источников (`direct`, `auto`, `mirror`);
  - Отображение картинок и гифок (JeetBot, Tenor, Giphy, Imgur, PicDrisnya);
  - **Все 540+ официальных графических бейджей Twitch**, включая все игровые Drops (Elden Ring, Fallout, Borderlands и др.) и саб-тиры канала;
  - **Интерактивный блок в шапке чата**: живые голосования (**Twitch Polls**) с обратным отсчетом и ASCII-прогресс-барами, ставки и прогнозы (**Twitch Predictions**);
  - Выделенные системные плашки анонсов стримера и модераторов (`/announce`);
  - Награды за баллы канала (**Channel Points**);
  - Компактная типографика на пропорциональном шрифте **`IBM Plex Sans`** с нативной кириллицей (+75% к вместимости сообщений на экране).
- **Голосовые донаты (TTS) и алерты**:
  - Классические вспышки донатов с суммой, ником и сообщением;
  - Полноценная поддержка голосовых донатов **DonateX** (голос донатера, платные голоса, реплики ИИ-персонажей) и аудиосообщений **DonationAlerts**;
  - **Динамический таймер алерта**: оверлей автоматически растягивает время показа и ASCII-прогресс-бар под реальную длину звучания аудиодорожки.
- **Заказ треков с YouTube (Media Request)**:
  - Карточка с плеером 16:9, последовательная очередь воспроизведения (FIFO) из донатов DonateX и DonationAlerts, автопропуск по окончании ролика.
- **Динамические терминальные фоны**:
  - Аппаратные эффекты без нагрузки на GPU: медленный дрифт сетки (`drift`), центральное дыхание (`pulse`), технический тикер координат (`matrix`) с авто-адаптацией под состояние сцены.
- **Кастомные звуки алертов**:
  - Выбор и назначение аудиофайлов (`.wav`, `.mp3`, `.ogg`) под каждое событие и загрузка новых звуков прямо через веб-панель.
- **Встроенный пульт управления (OBS Control Dock)**:
  - Компактная 2-строчная мини-шапка с живой цветовой индикацией статусов сервисов (`● TW`, `● CHAT`, `● DA`, `● DX`);
  - Строгие терминальные кнопки: переключение состояний, управление таймером, пауза/скип треков, моментальный скип донатов в DonateX и DonationAlerts, очистка чата и быстрые dev-тесты.
- **Кросс-платформенность**: готовые скрипты запуска для Linux (`start.sh`) и Windows (`start.bat`, `start.ps1`).

## Быстрый старт

### 1. Запуск

#### Linux:
```bash
git clone https://github.com/Vokiry/OBS-Templates.git
cd OBS-Templates

# Боевой запуск эфира вместе с OBS Studio:
./start.sh --obs

# Запуск в режиме настройки (с веб-панелью конфигурации):
./start.sh --obs --settings
```

#### Windows:
```cmd
# Запуск из командной строки или двойным кликом:
start.bat

# Запуск в режиме настройки:
start.bat --settings

# Или в PowerShell:
.\start.ps1 -settings
```

Скрипт автоматически подготовит окружение Python, создаст файл конфигурации и запустит единый сервер:
- **Панель управления (OBS Dock)**: `http://localhost:8787/dock`
- **Веб-панель настроек (в режиме `--settings`)**: `http://localhost:8787/settings`
- **Коллекция сцен для OBS**: `obs/SYSTEM_Scene_Collection.json` (импортируется в 1 клик)

---

### 2. Подключение в OBS Studio

#### Импорт коллекции сцен (Рекомендуется)
1. В OBS Studio: **Коллекция сцен (Scene Collection) → Импорт (Import)**.
2. Выбери файл `obs/SYSTEM_Scene_Collection.json`.
3. В меню коллекций выбери **SYSTEM Broadcast Templates**.
4. Все 6 сцен созданы, источники 1920×1080 выставлены по слоям, прозрачность и звук включены. Остаётся лишь назначить захват экрана/игры и веб-камеру.

#### Добавление пульта управления (Custom Browser Dock)
1. В OBS: **Док-панели (Docks) → Пользовательские док-панели браузера (Custom Browser Docks)**.
2. Название: `SYSTEM Dock`, URL: `http://localhost:8787/dock`.
3. Нажми «Применить» — панель управления закрепится в интерфейсе OBS.

## Настройка интеграций

Настройку удобнее всего производить через графическую веб-панель, запустив `./start.sh --settings` и открыв **`http://localhost:8787/settings`** (или кликнув `[ CONFIG ]` в шапке OBS Dock).

Также параметры можно отредактировать напрямую в `bridge/config.toml`:

```toml
[server]
host = "127.0.0.1"
port = 8787

# 1. ЧАТ TWITCH (работает сразу, токены НЕ нужны)
[twitch_chat]
enabled = true
channel = "твой_ник_на_твиче"
# Источник 7TV смайлов: "direct" (рекомендуется с VPN) | "auto" | "mirror"
seven_tv_source = "direct"
seven_tv_mirror = "https://enhanced.jeetbot.cc"

# 2. СОБЫТИЯ TWITCH (сабы, рейды, битсы, опросы, прогнозы, бейджи)
[twitch]
enabled = false
client_id = ""
client_secret = ""
include_follows = false
redirect_url = "http://localhost:3000"

# 3. ДОНАТЫ DONATIONALERTS
[donationalerts]
enabled = false
client_id = ""
client_secret = ""
access_token = ""

# 4. ДОНАТЫ И ЗАКАЗ ТРЕКОВ DONATEX
[donatex]
enabled = false
token = ""
```

### Где взять ключи и токены: пошаговая инструкция

#### 1. Twitch Chat (`[twitch_chat]`) — без регистрации
- Никаких токенов не требуется: подключение идёт анонимно через официальный протокол Twitch IRC.
- В поле `channel` укажи логин своего канала на Twitch строчными буквами.
- Сразу работают: входящие сообщения, смайлы Твича, глобальные и канальные смайлы **7TV**, картинки/гифки и выделенные анонсы `/announce`.

---

#### 2. Twitch Events: сабы, рейды, битсы, опросы, бейджи (`[twitch]`)
Нужно создать своё бесплатное приложение в консоли Twitch для получения событий:

1. Перейди в [Консоль разработчика Twitch](https://dev.twitch.tv/console/apps/create) и войди под своим аккаунтом.
2. Заполни форму регистрации приложения:
   - **Name (Название)**: уникальное имя на английском, например `System-OBS-твойник`.
   - **OAuth Redirect URLs**: укажи `http://localhost:3000` и нажми кнопку **Add (Добавить)** рядом с полем.
   - **Category (Категория)**: выбери `Chat Bot` или `Application Integration`.
   - **Client Type**: оставь `Confidential`.
3. Нажми кнопку **Create (Создать)**, затем **Manage (Управление)** напротив приложения.
4. Скопируй **Client ID** и создай **New Secret** (Client Secret).
5. Вставь их в веб-панели настроек или в `config.toml` и включи `enabled = true`.
6. При первом старте в браузере откроется окно подтверждения Twitch — нажми «Авторизовать». Токен сохранится локально на ПК и будет обновляться автоматически.

---

#### 3. DonationAlerts (`[donationalerts]`)
1. Перейди в раздел приложений [DonationAlerts для разработчиков](https://www.donationalerts.com/application/clients).
2. Нажми «Создать приложение»:
   - Название: `SYSTEM Alerts`;
   - Redirect URI: `http://localhost:8787/api/da/callback`;
   - Scopes: отметь галочками `oauth-user-show` и `oauth-donation-subscribe`.
3. Скопируй `Client ID` и `Client Secret` в настройки.
4. Нажми **[ ПОДКЛЮЧИТЬ DONATIONALERTS ]** в веб-панели — авторизация выполнится автоматически в 1 клик!

---

#### 4. DonateX (`[donatex]`)
1. Войди в панель управления [donatex.gg](https://donatex.gg/).
2. Перейди в **Настройки → Api** (Settings → Api).
3. Скопируй свой **External token** (это бессрочный токен твоего аккаунта).
4. Вставь его в поле `token` в настройках и включи `enabled = true`.
5. Мост подключится к SignalR Hub донатов и музыкальному хабу: донаты с озвучкой и репликами ИИ будут воспроизводиться в алерте, а заказанные треки с YouTube — в музыкальной карточке.
