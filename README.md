# SYSTEM — OBS Broadcast Templates

TUI-inspired визуальная система для стрима в стилистике **system24**: эфир как строгий интерфейс технической системы с состояниями (`starting` → `main` → `chatting` → `focus` → `brb` → `ending`).

Тёмный монохромный UI, моноширинная типографика, живой чат со смайлами 7TV и медиаконтентом, вспышки донатов с сообщениями зрителей, таймер с управлением из OBS и модульные звуковые эффекты. Всё работает локально, без сторонних платных сервисов.

---

## Возможности

- **6 готовых сцен**: Starting Soon, Main (Gameplay), Chatting, Focus, Break (BRB), Ending.
- **Импорт в OBS за 1 клик**: готовый файл коллекции сцен `obs/SYSTEM_Scene_Collection.json`.
- **Встроенная панель управления (OBS Dock)**: переключение состояний, тест алертов, управление таймером и очистка чата прямо из интерфейса OBS.
- **Twitch-чат без токенов**: официальный анонимный Twitch IRC WebSocket, поддержка встроенных смайлов Twitch, глобальных и канальных смайлов 7TV, а также встроенное отображение картинок и гифок (JeetBot, Tenor, Giphy, Imgur).
- **Вспышки донатов**: классические flash-алерты с отображением суммы, ника и текста сообщения зрителя.
- **Кастомные звуки**: модульная папка `src/sounds/` с поддержкой любых `.wav` / `.mp3` и раздельной настройкой громкости под каждое событие.
- **Динамический таймер**: обратный отсчёт с установкой минут, паузой и сбросом в реальном времени из дока.
- **Локальный единый мост**: один процесс раздаёт статику, события WebSocket и API на порту `8787`.

## Быстрый старт

### 1. Клонирование и запуск

```bash
git clone https://github.com/Vokiry/OBS-Templates.git
cd OBS-Templates
./start.sh
```

Скрипт автоматически подготовит окружение Python, создаст файл конфигурации и запустит единый сервер.

- **Панель управления (OBS Dock)**: http://localhost:8787/dock (или просто http://localhost:8787/)
- **Коллекция сцен для OBS**: `obs/SYSTEM_Scene_Collection.json` (импортируется в 1 клик)

---

### 2. Подключение в OBS Studio

#### Импорт коллекции сцен (Рекомендуется)
1. В OBS Studio: **Коллекция сцен (Scene Collection) → Импорт (Import)**.
2. Выбери файл `obs/SYSTEM_Scene_Collection.json`.
3. В меню коллекций выбери **SYSTEM Broadcast Templates**.
4. Все 6 сцен созданы, источники 1920×1080 выставлены по слоям, прозрачность и звук включены. Остаётся лишь назначить захват экрана/игры и веб-камеру.

#### Добавление пульта управления (Custom Browser Dock)
1. В OBS: **Док-панели (Docks) → Пользовательские док-панели браузера (Custom Browser Docks)**.
2. Название: `SYSTEM Dock`, URL: `http://localhost:8787/dock`.
3. Нажми «Применить» — панель управления закрепится в интерфейсе OBS.

## Настройка интеграций (`bridge/config.toml`)

Файл `bridge/config.toml` создаётся автоматически при первом запуске `./start.sh` (копируется из примера). Открой его в любом текстовом редакторе.

```toml
[server]
host = "127.0.0.1"
port = 8787

# 1. ЧАТ TWITCH (работает сразу, токены НЕ нужны)
[twitch_chat]
enabled = true
channel = "твой_ник_на_твиче"

# 2. СОБЫТИЯ TWITCH (сабы, рейды, битсы)
[twitch]
enabled = false
client_id = ""
client_secret = ""
include_follows = false

# 3. ДОНАТЫ DONATIONALERTS
[donationalerts]
enabled = false
access_token = ""

# 4. ДОНАТЫ И ЗАКАЗ ТРЕКОВ DONATEX
[donatex]
enabled = false
token = ""
```

---

### Где взять ключи и токены: пошаговая инструкция

#### 1. Twitch Chat (`[twitch_chat]`) — без регистрации
- Никаких токенов не требуется: подключение идёт анонимно через официальный протокол Twitch IRC.
- В поле `channel` укажи логин своего канала на Twitch строчными буквами (например, если ссылка `twitch.tv/vokiry`, то `channel = "vokiry"`).
- Сразу заработают: входящие сообщения зрителей, встроенные смайлы Твича, глобальные и канальные смайлы **7TV** (с обходом блокировок) и картинки/гифки из расширения **JeetBot**.

---

#### 2. Twitch Events: сабы, рейды, битсы (`[twitch]`)
Нужно создать своё бесплатное приложение в консоли Twitch для получения событий:

1. Перейди в [Консоль разработчика Twitch](https://dev.twitch.tv/console/apps/create) и войди под своим аккаунтом.
2. Заполни простую форму регистрации приложения:
   - **Name (Название)**: любое уникальное имя на английском, например `System-OBS-твойник` (если занято, добавь пару цифр).
   - **OAuth Redirect URLs**: обязательно укажи `http://localhost:3000` и нажми кнопку **Add (Добавить)** рядом с полем. *Именно на этот локальный порт библиотека `twitchAPI` принимает одноразовое подтверждение при первом старте.*
   - **Category (Категория)**: выбери `Chat Bot` или `Application Integration`.
   - **Client Type**: оставь `Confidential`.
3. Нажми внизу кнопку **Create (Создать)**.
4. В списке приложений нажми **Manage (Управление)** напротив созданного приложения.
5. На странице приложения:
   - Скопируй значение поля **Client ID** в `client_id = "..."` в `config.toml`.
   - Нажми кнопку **New Secret (Создать секрет)**, подтверди и скопируй появившуюся строку в `client_secret = "..."`. *(Сохрани секрет сразу — Twitch показывает его только один раз).*
6. Поставь `enabled = true`.
7. **Первый запуск**: при запуске `./start.sh` в браузере автоматически откроется страница подтверждения авторизации Twitch. Нажми «Авторизовать». Токен сохранится локально на твоем ПК и будет обновляться автоматически в фоне.

---

#### 3. DonationAlerts (`[donationalerts]`)
1. Перейди в раздел приложений [DonationAlerts для разработчиков](https://www.donationalerts.com/application/clients).
2. Нажми «Создать приложение»:
   - Название: `SYSTEM Alerts`;
   - Redirect URI: `http://localhost`;
   - Права (Scopes): отметь галочкой `oauth-donation-subscribe`.
3. Скопируй полученный `access_token` в поле `access_token = "..."` в `config.toml`.
4. Поставь `enabled = true`.

---

#### 4. DonateX (`[donatex]`)
1. Войди в панель управления [donatex.gg](https://donatex.gg/).
2. Перейди в раздел виджетов донатов или сбора:
   - Если у тебя есть ссылка на виджет вида `https://donatex.gg/widgets/donations/13146160-88cb-4865-a751-eac5a8a094c3`, то идентификатор в конце ссылки (`13146160-88cb-4865-a751-eac5a8a094c3`) является твоим токеном подключения.
   - Либо скопируй API-ключ из настроек профиля.
3. Вставь его в `token = "..."` в секции `[donatex]` и поставь `enabled = true`.
4. Мост начнёт принимать входящие донаты и автоматически воспроизводить заказанные треки с YouTube через оверлей `media-request`.
