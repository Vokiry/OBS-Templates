## Отложенные решения

- **Сообщения зрителей** в алертах (CHEER/RESUB/DONATE): показывать текст или
  только сумму. Схема события поддерживает message — вопрос отображения.
- **Follow-алерты**: выключены по умолчанию (шум), включаются параметром
  `?follow=1` и скоупом `moderator:read:followers`.
- **Динамические фоны**: пользователь хочет «динамичный паттерн» для пустых
  сцен — форма не выбрана, решается вместе с переходами.
- **Логика плеера в starting-сцене**: сцена объединяет countdown и музыку;
  поведение при отсутствии играющего трека нужно определить при написании
  плеер-адаптера.
- **Ending-сцена**: реальный оффлайн-экран закрывается заглушкой Twitch;
  кастомная страница — опционально.

## Принятые ключевые решения (хронология)

1. TUI-эстетика как общий язык; палитра BASE/SURFACE/ACCENT/TEXT/MUTED/DANGER.
2. Шрифты Space Grotesk (display) + IBM Plex Mono (interface); базовый вес
   интерфейсного текста 600.
3. WARNING `#E9B13C` (глубокое золото), DANGER `#E5484D` (глубокий красный) —
   ярче и глубже исходных, но в палитре.
4. Сплит на прозрачные оверлеи вместо монолитных страниц: слои собираются в OBS,
   компонент позиционируется `?pos=`, холст фикс. 1920×1080.
5. Алерты — простое окошко с тонкой обводкой; анимация: новый вырастает сверху,
   старые сдвигаются вниз; печать заголовка со spinner + ASCII-прогресс-бар.
6. Мост: локальный демон без публичного URL; события нормализуются в
   `{type:"alert", title, body}`; оверлей переподключается сам.
